# Third-party projects

This public directory contains Ryoku scripts only; it does **not** redistribute original third-party source, proprietary device drivers, Google credentials or wallpapers.

- [Omarchy](https://github.com/omacom/omarchy): upstream desktop and shell.
- [Hyprland](https://github.com/hyprwm/Hyprland): compositor and native pinch zoom.
- [Quickshell](https://quickshell.org/): runtime for the Omarchy bar.
- [fldc/omarchy-tray](https://github.com/fldc/omarchy-tray): required external dropdown tray fork.
- [Omagoocal](https://github.com/huligabuliga/Omagoocal): optional external Google Calendar plugin.
- [omarchy-downloads](https://github.com/jankeesvw/omarchy-downloads): optional downloads.
- [Resonance](https://github.com/ShravyaKudlu/omarchy-plugin-resonance): optional music spectrum.

Names and trademarks are used for compatibility identification, with no affiliation or endorsement.
